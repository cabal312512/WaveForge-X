# Compact numerical references

`seeded_smoke.json` contains actual counts from the checked-in small AWGN
configuration, recorded by running `MonteCarloRunner`. It is a deterministic
software regression, not evidence for a waveform performance claim. The file
records its numerical environment. Runtime, output paths and timestamps are
excluded from comparisons. Update counts only after explaining an intended
model or algorithm change and revalidating the independent mathematical tests.
